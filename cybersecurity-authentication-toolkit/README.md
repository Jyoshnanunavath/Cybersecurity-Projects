VD — Secure Authentication Toolkit

A frontend-only cybersecurity dashboard that demonstrates five authentication and security concepts entirely in the browser — no backend, database, or server required.
The complete application runs from a single HTML file using HTML, CSS, and vanilla JavaScript.
Live Demo
Launch Secure Authentication Toolkit
Features
1. Password Strength Checker
Evaluates password strength using multiple security criteria, including:
Password length
Uppercase and lowercase characters
Numbers
Special characters
Real-time strength feedback and visual meter
2. Login Lockout Simulator
Demonstrates an account lockout mechanism after repeated failed login attempts.
Three-attempt limit
Fixed demonstration credentials
Real-time attempt tracking
Account lockout simulation
Demo credentials: admin / Secure@123
3. Secure Password Generator
Generates customizable passwords based on user-selected requirements.
Adjustable password length
Uppercase characters
Lowercase characters
Numbers
Special characters
Guaranteed inclusion of selected character types
One-click copy functionality
4. Brute Force Attack Detection
Analyzes sample login activity and identifies suspicious IP addresses based on repeated failed authentication attempts.
The simulator flags IP addresses with three or more failed login attempts.
5. Password Guessing Detection
Analyzes sample authentication records to identify usernames targeted with multiple unique password guesses.
The simulator flags usernames associated with three or more unique guessed passwords.
Navigation
The toolkit uses a lightweight hash-based client-side router, allowing users to navigate between modules without page reloads.
Example routes include:
#password-checker
#login-lockout
#password-generator
#brute-force
#password-guessing

Tech Stack
Technology	Purpose
HTML5	Application structure
CSS3	UI design and responsive styling
Vanilla JavaScript (ES6)	Application logic and interactions
Google Fonts	Typography
Font Awesome	Interface icons

No frameworks, build tools, or external backend services are required.
How to Run Locally
Clone the repository
git clone https://github.com/ddakshatha18-spec/Cybersecurity-Authentication-Toolkit.git
cd Cybersecurity-Authentication-Toolkit

Option 1 — Open directly
Open index.html in any modern web browser.
Option 2 — Run a local server
python3 -m http.server 8000

Then open:
http://localhost:8000

Project Scope
This project is designed as an educational cybersecurity simulation demonstrating common authentication-security concepts through an interactive browser-based interface.
All attack-detection data, login records, IP addresses, and password-guessing examples are static sample data included for demonstration purposes.
This project is not intended to be used as production-grade security software.
Future Enhancements
Backend-based authentication
Database-backed login monitoring
Real-time security event logging
Configurable account lockout policies
Real authentication log analysis
Advanced anomaly and intrusion detection
User authentication and role-based access control
