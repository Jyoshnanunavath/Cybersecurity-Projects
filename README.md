# Cybersecurity and Network Analysis Projects

## Overview

This repository contains academic assignments and practical implementations developed as part of my coursework in cybersecurity and computer networking. The projects focus on understanding network behaviour, diagnosing connectivity issues, and applying networking and security concepts through hands-on development.

## Projects

### 1. Traceroute Visualizer

A Python-based web application that visualizes the network path between a source computer and a destination host. It presents hop-by-hop information, IP addresses, response times, and probe statuses to help analyse network routes and identify possible delays.

**Technologies:** Python, Streamlit, Pandas, Traceroute

**Features:**
- Accepts a destination domain or IP address.
- Displays intermediate network hops.
- Shows available response times and probe statuses.
- Helps identify possible network delays and non-responsive hops.
- Provides a visual representation of traceroute results.

**Source Code:** [`traceroute-visualizer`](./traceroute-visualizer/)
